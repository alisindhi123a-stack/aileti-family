# عائلتنا ❤️

نسخة أولية لتطبيق عائلي خاص باللغة العربية.

## التشغيل
1. ثبّت Flutter.
2. افتح المجلد في Android Studio أو VS Code.
3. نفّذ:
   flutter pub get
   flutter run

## ملاحظة
هذه نسخة UI/Prototype قابلة للتشغيل. ميزات المكالمات الحقيقية، Firebase Authentication/Firestore/Storage، التسجيل الصوتي والفيديو، وPush Notifications تحتاج ربط الخدمات وإعدادات Android/iOS قبل أن تصبح إنتاجية.
